BACY — LIGHTWEIGHT ONLINE BUILD

WHAT CHANGED
- The old robot/3D scene and Three.js files were removed completely.
- The interface was rebuilt from scratch as a lightweight chat-first desktop UI.
- No canvas renderer, robot animation, mouth animation, large portrait, or heavy blur effects are used.
- Chat, microphone, Hands-free, Live talk, Connections, and Windows controls remain.
- The app no longer tests every remote service while the page is opening. This makes startup/navigation feel faster.
- Gemini is the required online AI brain.
- Bacy prefers a low-latency Gemini Flash-Lite model and automatically falls back to compatible Flash models.
- Gemini retries were reduced so a bad/busy model does not make the whole UI appear frozen for a long time.
- The Send button becomes a Stop button while Bacy is answering.
- Replies show the actual response time in seconds.

VOICE SPEED
- Fast voice is now the default. It uses the Windows/browser speech engine and starts almost immediately.
- Natural voice is optional and uses ElevenLabs.
- ElevenLabs uses Flash v2.5 and a streaming endpoint when the browser supports streamed MP3 playback.
- The UI no longer has a robot mouth, so there is no lip-sync mismatch.
- Microphone input tries the browser's live SpeechRecognition first because it can show words immediately.
- When browser live transcription is unavailable, Bacy can fall back to ElevenLabs transcription.
- For a normal voice note, Bacy records in parallel when ElevenLabs is connected, so a browser speech-service failure does not force a full app restart.
- Hands-free and Live talk can also fall back to short ElevenLabs transcription segments, with shorter silence detection than the previous build.

GMAIL MCP
- A new Connections screen includes Gmail through Model Context Protocol (MCP).
- The build targets Google's official Gmail remote MCP server:
  https://gmailmcp.googleapis.com/mcp/v1
- Gmail MCP uses Google OAuth 2.0. Bacy never asks for your Gmail password.
- Bacy can discover whatever Gmail tools Google exposes to your account and let Gemini call them for email requests.
- Read-only tools are available for normal email questions.
- Bacy only exposes modifying Gmail tools to Gemini when your message clearly asks for an action such as creating a draft or changing a label.
- Email/tool output is treated as untrusted data so instructions hidden inside emails are not supposed to become Bacy instructions.
- Google's Gmail MCP is currently a Google Workspace Developer Preview feature. Your Google Cloud project must be eligible and have the required Gmail/Gmail MCP services and OAuth client configured.
- The OAuth redirect URI to add in Google Cloud is:
  http://127.0.0.1:3000/api/gmail/oauth/callback

FIRST START
1. Extract the ZIP into a NEW folder.
2. Double-click START-BACY.cmd.
3. Keep the black window open.
4. Bacy opens at http://127.0.0.1:3000.
5. If Gemini is not saved yet, Bacy shows one simple Gemini connection screen.
6. Voice and Gmail are optional and can be connected later under Connections.
7. Allow microphone access in Chrome or Edge if you want voice input.

GEMINI
- Put your Gemini API key only inside Bacy's Connections screen.
- Do not paste API keys into chat.
- Remembered keys are encrypted for the current Windows account with Windows DPAPI.
- Bacy prefers the text model returned by Test connection for fast everyday replies and can fall back to current Flash models such as gemini-3.8-flash when needed.

ELEVENLABS
- In ElevenLabs, keep API-key restrictions enabled.
- Allow Text to Speech, Speech to Text, and voice-list/read permission if your key settings show those controls.
- Connect the key in Bacy > Connections.
- Choose Natural under Settings if you want ElevenLabs replies.
- Leave Fast selected when response speed matters more than voice quality.

WINDOWS CONTROL
These still run locally on the laptop:
- open Chrome
- open Notepad
- open Word
- open calculator
- show desktop
- volume up / volume down / mute
- search for <something>
- show files

SECURITY
- Bacy listens only on 127.0.0.1.
- Browser POST requests use a random local-session token.
- API keys/secrets are not returned to the webpage after saving.
- Saved Gemini, ElevenLabs, and Gmail OAuth settings use Windows DPAPI encryption.
- Gmail OAuth tokens are stored in the same encrypted Windows-user context when Remember is enabled.
- File access still requires you to choose a folder and is restricted to that folder.
- TLS certificate verification remains enabled.

IMPORTANT LIMITS
- I/O speed still depends on your internet connection and each online provider's own response time/quota.
- ElevenLabs cloud transcription cannot be truly instant because audio must travel to the service and back. Browser live transcription is used first when available.
- Google's Gmail MCP feature requires Google's Developer Preview eligibility; the code cannot bypass that requirement.
- This build does not send Gmail messages directly. Google's current Gmail MCP toolset creates drafts and manages mail/labels; you can review a draft before sending it in Gmail.

TESTING
