# Loop Secure downloads

Customer **0.21.0/code 34**, administrator **1.9.0/code 15**. Android 11+.

- **Loop-Secure-Client.apk**: signed customer update. Install over the existing customer app; do not clear data or uninstall.
- **Loop-Secure-Client-Update.zip**: extract, connect one enrolled phone, then double-click START-HERE.cmd. Account and device ownership stay in place.
- **Loop-Secure-Admin.apk**: current native administrator app; unchanged in this customer release.
- **Loop-Secure-Source.zip**: public sources, including the customer redesign and bundled-font licenses.
- **Loop-Secure-USB-Helper.zip**: helper sources. New customer enrollment requires a private customer-specific bundle from the admin dashboard.

The new customer app replaces purple/gold styling with white and black and adds bank search, saved support drafts, copyable payment records, calendar reminder drafts and a Home payment-status check. [Details](../docs/MONOCHROME_CUSTOMER_REBUILD.md).

Enrolled customers can receive this release through the managed updater where Android permits. Older updater versions may require installation approval. Immediate installation is not guaranteed on every phone. Native admin updates never restrict the administrator phone. No ChatGPT/Codex subscription is required at runtime.

The preview APK is a separate, older disconnected design preview; use the customer APK for this release.
