# Customer update 0.18.2 — full download over 10 MB

This is another real release on the signed customer update channel. The full APK download is approximately 18.2 MB; no extra filler assets are needed.

The release adds the realistic phone-padlock logo and the R1,700 total/paid/balance/progress display. **App updates** also includes:
- Installation date/time as reported by Android.
- Size of the update APK cached on the phone, or No saved download when absent.
- A direct Open Wi-Fi settings shortcut.

After installation, Home shows **v0.18.2**, and the gold What’s new strip describes these additions. The administrator app is 1.7.1 with the same new phone-padlock logo.

Keep your existing 0.18.0 or 0.18.1 customer app installed and enrolled. Connect to unmetered Wi-Fi with internet, close/reopen Loop Secure and wait for the download. Tap Install update, approve Android if prompted, then open the app and check for **v0.18.2**. Allow one minute between reopening attempts if a check has just run. Installing the APK manually first skips the automatic-download test.

Downloads are automatic; approval is still required for installation. Existing customer/account data and device ownership are retained. A device that is released or no longer managed is outside the managed customer update channel. Real download/install success must be confirmed on the handset; server publication alone does not prove it.
