New customer enrollment ZIPs are private and must be generated in the dashboard. Public downloads do not assign Android device ownership or link a customer. Existing linked phones should retain app data and use compatible signed updates. Future builds need newer version codes and the original package/signer; GitHub CI publication is a template until privately configured.

The independent Rain evaluation is separate from these production apps. Read [continuation instructions](loop-secure/PRODUCTION-CONTINUATION.md) before deploying: the live production backend/website changed outside the older source baseline and require comparison before replacement.
